# Security policy

Found a vulnerability in DevStream? Please report it privately, not in a public issue, discussion or pull request.

1. Open the [Security tab](https://github.com/devstreamhq/devstream/security) of this repo.
2. Select **Report a vulnerability**.
3. Tell us what you found, how to reproduce it and what an attacker could do with it.

Only the maintainers can see your report. We'll reply in the advisory and keep you posted while we work on a fix.
